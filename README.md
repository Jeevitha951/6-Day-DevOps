# 6-Day DevOps Hands-On Training

This repository contains notes and summaries of 6-day DevOps hands-on workshop. The training covered a variety of topics from setting up environments, containerization, working with Kubernetes, to monitoring with Prometheus and Grafana.

## Overview

The workshop focused on providing hands-on experience with core DevOps tools and practices. Key concepts like containerization, orchestration, CI/CD, cloud computing, and monitoring were covered to enable efficient software development and deployment.

## Tools & Technologies Used
- **AWS**: EC2, S3, CLI for cloud resource management.
- **Docker**: Containerization for packaging and running applications.
- **Kubernetes**: Orchestration for managing and scaling containerized applications.
- **Prometheus & Grafana**: Monitoring and visualization of system performance.
- **Git & GitHub**: Version control and collaboration for code management.

## Key Concepts Learned

- 🖥️ **Linux File System Navigation**: Essential command-line tools to navigate and manage files.
- 🐳 **Docker**: Building, running, and managing containers using Docker.
- ☸️ **Kubernetes**: Deploying applications, managing pods, services, and scaling workloads in clusters.
- 🌐 **Exposing Applications**: Using Kubernetes services (like LoadBalancer) to expose applications to external traffic.
- 📡 **Monitoring**: Setting up Prometheus to collect metrics and Grafana to visualize data for system monitoring.
- 🔁 **CI/CD Pipelines**: Automating the process from code to deployment for faster delivery cycles.

## ✅ Summary

- Gained experience with **containerization** and **orchestration**.
- Learned to scale and deploy applications with **Kubernetes**.
- Set up **monitoring** with **Prometheus** and **Grafana** to ensure system health.
- Familiarized with **DevOps workflows** to automate deployment and management.

This repository serves as a reference for all the concepts and tasks completed during the training. It captures the practical application of DevOps principles that can be further built upon.
