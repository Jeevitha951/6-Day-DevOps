## What I Learned About DevOps

DevOps stands for **Development + Operations**. It's more than just a buzzword—it's a set of practices that help dev and ops teams work together more efficiently. The main goal is to speed up software delivery without compromising on quality.

Some key takeaways:
- Better collaboration between different teams
- Automating repetitive tasks (like testing or deployments)
- Using continuous integration and delivery (CI/CD) pipelines to push code changes faster
- Keeping an eye on system performance and taking feedback into account

---

## DevOps Workflow 

We discussed the typical stages in a DevOps pipeline. Here's a simplified version of how the process flows:

1. **Plan** – Figure out what needs to be built  
2. **Code** – Developers write and manage code (usually in Git)  
3. **Build** – Compile the code automatically  
4. **Test** – Run tests to catch bugs early  
5. **Release** – Prepare code for deployment  
6. **Deploy** – Push the changes to production or staging environments  
7. **Operate** – Keep things running smoothly  
8. **Monitor** – Track performance and user feedback  

These stages help create a smooth cycle of continuous improvement.

## AWS Account – Getting Started

Later in the day, we went through the process of creating an AWS account. AWS (Amazon Web Services) is widely used in DevOps for hosting applications and managing infrastructure in the cloud.

Steps I followed:
1. Went to [aws.amazon.com](https://aws.amazon.com/)
2. Signed up using my email and set a password
3. Added personal details like phone number and address
4. Entered card details (used for verifying identity, not billing unless extra services are used)
5. Verified phone number via OTP
6. Selected the **Basic Free Tier** plan
7. Successfully logged into the AWS Management Console
